# SmartSend — prévia segura

Prévia visual do painel. Esta versão **não conecta ao WhatsApp e não envia mensagens**; os contatos exibidos são fictícios.

## Executar localmente

Com Python 3 instalado, execute na pasta do projeto:

```bash
python3 -m http.server 4173
```

Acesse `http://localhost:4173`.

O ZIP funcional original não está neste repositório. A prévia foi separada para permitir avaliação da interface sem habilitar disparos automatizados.
